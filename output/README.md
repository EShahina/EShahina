# 🐍 GitHub Snakes

This directory contains the GitHub contribution snake animation for the profile.

## How to Update

1. The snake animation is generated automatically
2. It shows your contribution activity as a snake eating
3. Updated daily via GitHub Actions

## Files

- `github-contribution-grid-snake.svg` - Light mode snake
- `github-contribution-grid-snake-dark.svg` - Dark mode snake

## Customization

To customize the snake colors, edit the GitHub Actions workflow in `.github/workflows/snake.yml`.
